🛠️
开发工具链
5 个
#1 官方
GitHub MCP Server
GitHub 官方维护的 MCP Server，提供完整的仓库管理、Pull Request、Issue、Actions 等 API 能力。AI 助理可直接创建 PR、审查代码、管理项目。
Go / TypeScript github API 集成
#2 官方
Git MCP
MCP 官方参考实现之一。直接在本地仓库执行 git 操作：查看 diff、log、branch，创建提交，搜索历史。最基础也最常用的开发 MCP。
Python modelcontextprotocol 开发工具
#3
Figma Context MCP
将 Figma 设计稿信息直接注入 AI 编码助手。AI 能"看懂"设计稿的布局、颜色、间距，直接生成匹配的前端代码，极大提升 Design-to-Code 效率。
TypeScript GLips 设计→代码
#4
shadcn/ui MCP Server
为 AI 提供 shadcn/ui 组件库的完整上下文——组件结构、用法、安装方式。支持 React / Svelte 5 / Vue / React Native，前端开发必备。
TypeScript Jpisnice UI 组件库
#5
Microsoft Learn MCP
微软官方文档 MCP Server。为 AI 提供实时、可信的 Microsoft 技术文档和代码示例，涵盖 Azure、.NET、PowerShell 等。
TypeScript MicrosoftDocs 文档知识库
🌐
浏览器 & Web 自动化
4 个
#1 微软
Playwright MCP
微软官方出品的浏览器自动化 MCP。基于 Playwright 引擎，AI 可操控 Chromium/Firefox/WebKit 浏览器——点击、填表、截图、执行 JS，用于测试和网页交互。
TypeScript microsoft 浏览器自动化
#2
Firecrawl MCP Server
最强 Web 抓取 MCP。将任意网页转为 LLM 友好的 Markdown，支持 JavaScript 渲染、爬取、搜索。是 AI 获取实时网络信息的关键通道。
TypeScript firecrawl 网页抓取
#3
Browserbase MCP
云端浏览器自动化。结合 Browserbase 和 Stagehand，AI 可在云端无头浏览器中执行复杂操作，比本地 Playwright 更适合规模化任务。
TypeScript browserbase 云端浏览器
#4
Fetch MCP
官方轻量级 HTTP 获取 MCP。将网页内容转成 Markdown 供 LLM 消费。适合简单的网页内容提取，不依赖浏览器引擎。
TypeScript modelcontextprotocol HTTP 客户端

企业协作 & 办公
5 个
#1
Atlassian MCP
Confluence + Jira 双剑合璧。AI 可以搜索知识库、读写文档、管理 Issue、操作 Sprint，是 Atlassian 生态用户的必备 MCP。
Python sooperset 项目管理
#2
Slack MCP Server
功能最强的 Slack MCP：不需要特殊权限，支持 Apps、GovSlack、DM、群组 DM，智能历史获取。AI 可以读消息、发消息、搜索频道。
TypeScript korotovsky 即时通讯
#3
Excel MCP Server
读写 Excel 文件（.xlsx/.xls）。AI 可以创建、修改电子表格，执行公式计算，数据清洗。数据分析师和财务人员的 AI 助手。
Python haris-musa 办公文档
#4
LinkedIn MCP Server
AI 访问 LinkedIn 数据：profile、公司信息、职位搜索、消息。用于招聘自动化、销售线索研究、人脉管理。
TypeScript stickerdaniel 社交平台
#5
WhatsApp MCP
通过 WhatsApp Web 接口实现消息收发。AI 可自动回复、群发消息、管理对话。适合客服自动化和个人消息助理。
TypeScript lharries 即时通讯

云平台 & 基础设施
4 个
#1 AWS
AWS MCP
AWS 官方 MCP 服务器集合。覆盖 S3、DynamoDB、Lambda、EC2 等核心服务。AI 可直接管理云资源，实现基础设施即对话。
Python / TS awslabs 云平台
#2
Kubernetes MCP Server
由 containers 组织维护的 K8s/OpenShift MCP。AI 可管理 Pod、Deployment、Service，查看日志，排查故障。云原生运维利器。
Go containers 容器编排
#3
Google MCP Toolbox
Google 官方数据库 MCP。统一接口连接 MySQL、PostgreSQL、SQLite、BigQuery 等多种数据库，AI 可进行查询、分析、Schema 检查。
Python googleapis 多数据库
#4
Windows MCP
Windows 桌面自动化 MCP。AI 可操控 Windows 应用、文件系统、系统设置，实现桌面级 AI Agent。
Python CursorTouch 桌面自动化
🧠
推理增强 & 数据智能
5 个
#1
Sequential Thinking MCP
官方推理增强 MCP。通过动态思维链（Chain of Thought）让 AI 进行多步骤、可回溯的深度推理。解决复杂问题时大幅提升准确率。
TypeScript modelcontextprotocol 推理引擎
#2
Memory MCP
官方知识图谱持久记忆系统。AI 可跨会话记住实体、关系和事实。实现长期记忆和上下文延续，告别"每次重来"的体验。
TypeScript modelcontextprotocol 记忆系统
#3
Exa MCP Server
AI 原生的搜索引擎 MCP。支持语义搜索和网页爬取，专为 LLM 优化——返回结构化、高质量的内容，而非传统搜索引擎的链接列表。
TypeScript exa-labs AI 搜索
#4
Qdrant MCP Server
官方 Qdrant 向量数据库 MCP。AI 可存储、搜索、管理向量嵌入。RAG 应用和语义检索场景的核心基础设施。
Python qdrant 向量数据库
#5
MCP Server Chart (AntV)
蚂蚁 AntV 团队出品的数据可视化 MCP。支持 25+ 图表类型——折线图、柱状图、饼图、散点图等。AI 可直接根据数据生成可视化图表。
TypeScript antvis 数据可视化

💡 关键洞察

🏗️
生态爆发式增长
2024 年 11 月 MCP 协议发布后，社区迅速响应。仅半年时间就有 500+ 社区 MCP Server，覆盖几乎所有主流开发工具和平台。
🏢
大厂全面入局
Microsoft、AWS、Google、GitHub、Anthropic 均已推出官方 MCP Server。这标志着 MCP 正成为 AI Agent 工具集成的事实标准。
🔌
浏览器是第一入口
Playwright MCP (30K★) 和 Firecrawl MCP (17K★) 高居社区热度榜首。浏览器自动化是 AI Agent 连接互联网的核心通道。
🧩
从工具到平台
MCP 已不限于"给 AI 接个 API"。Figma→代码、设计→开发、Exa 语义搜索 —— MCP 正在重塑人机协作的生产力范式。
